## Overview

A library management system built in **Java** and **JavaFX** on top of **MySQL**. Librarians can manage the catalogue, register members and handle the full issue/return lifecycle.

## Features

- Secure login and account creation
- Book catalogue with search
- Member management
- Issue, return and transaction records

## What I learned

Designing the database first (the ER model is in the repo) made the Java side almost write itself.
