## Overview

A point-of-sale system built for small retail businesses. The **React** + **Tailwind CSS** front-end is designed for speed at the till, and a **Spring Boot** REST API handles products, orders and reporting on top of **MySQL**.

## Features

- Product management — create, update and track items
- Billing — build an order, calculate totals and checkout
- Daily sales reports

## What I learned

Moving from desktop JavaFX apps to a React + Spring Boot split taught me how to design an API contract first, so front-end and back-end can evolve independently.
